# Áudios da unidade A live começou

Adicione gravações próprias ou autorizadas em MP3 neste diretório. Use o texto coreano correspondente de `src/data/live.ts` e estes nomes:

| Lição | Pergunta | Resposta | Aplicação |
|---|---|---|---|
| Cumprimentar | live-cumprimentar-opening.mp3 | live-cumprimentar-reply.mp3 | live-cumprimentar-transfer.mp3 |
| Som | live-som-opening.mp3 | live-som-reply.mp3 | live-som-transfer.mp3 |
| Agradecer | live-agradecer-opening.mp3 | live-agradecer-reply.mp3 | live-agradecer-transfer.mp3 |

Peça revisão de pronúncia e naturalidade antes de incorporar. Prefira uma gravação diferente na coluna Aplicação. A build inclui os clipes automaticamente. Na ausência de clipe, o app tenta uma voz coreana local do próprio dispositivo, identificada na interface.
